# Roadster Flight Lab

浏览器 3D 喷气跑车无尽驾驶游戏。三张地图、手机强制横屏、键盘与多指触控、在线排行榜。

## 启动

Mac 双击 `启动游戏.command`，或使用 Node.js 22+：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/>。Three.js 和美术资源在本地，不依赖运行时 CDN。

## 手动无尽驾驶

车辆不会自动前进，也不会跟随弯道调整车头。左侧 360° 轮盘上推给油、下推先减速再倒车，左右转向；左上／右上同时控制油门与方向。松手靠惯性滑行，刹车可以完全停住。普通前进最高约 130 km/h，倒车最高约 50 km/h，喷气最高约 295 km/h。气压为零仍能使用普通电机驾驶。没有电池、压缩机、充电站或固定终点。

初始血量 100。撞击路障扣 25，侧翻或重落地扣 20；受伤后有 1.15 秒保护。车辆离开路面后保留世界坐标中的速度并受重力影响，能使用侧喷、升力或吸地尝试挽救。**只有血量归零或坠落撞到下方地面才结束**，不会因为关吸地超过固定时间、或刚离开赛道就失败。桥面下方不能直接吸穿桥面，上撞桥底会受损。

结束时无论原因都保存成绩，可以提交排行榜。主动返回车库视为放弃本轮。

## 气压与技巧

| 动作 | 气压变化 | 条件 |
| --- | --- | --- |
| 穿环 | +25% | 真正穿过光环，每环只结算一次 |
| 漂移 I / II / III | +8% / +16% / +24% | 有效侧滑至少 0.65 / 1.4 / 2.2 秒，且向新路段推进至少 10 / 25 / 45 米 |
| 后喷加速 | −16% / 秒 | 按住，刹车优先 |
| 下喷腾空 | −14% / 秒 | 按住，吸地关闭 |
| 侧喷 | −7% / 秒 | 按住，模拟摇杆空中转向也使用侧喷 |
| 翻滚 | −10% / 次 | 空中点按，1.25 秒完成单圈并回正；高度、气压充足时可用 |
| 吸地 | −5% / 秒 | 开关控制，在普通路面和特殊路段均耗气 |

气压上限 100%，初始满气。只有穿环、成功漂移会补气；不随时间恢复。普通电机驾驶不耗气。

有速度时，关闭吸地，按住刹车＋转向进入漂移，继续给油维持速度。松开刹车立即结束漂移并结算，获得气压、距离分和 0.45 / 0.7 / 1 秒的出弯加速。蓝、金、紫色进度分别表示三档。碰撞或离开路面会打断未结算的漂移，不能靠原地打方向或反复经过旧路段刷气。车头方向与惯性方向分开计算，结束漂移后约 0.35 秒内平顺恢复轮胎抓地。

每张地图循环出现 **90° 侧墙、180° 倒挂、360° 螺旋翻转**。道路沿行进方向旋转，车辆和跟车镜头随道路法线翻转。紫色入口提前提示吸地；特殊路段禁止漂移、腾空与翻滚，必须留气开启吸地。失去吸附后按实际重力滑落或坠落。车仍在桥面正面附近、横向没有超出赛道且气压足够时，重新打开吸地会施加回吸力；作用距离为 15 米，回吸结果取决于距离与速度，不会瞬移或重置车道。这里的 360° 是道路绕行进轴的螺旋翻转。

## 操作

| 功能 | 电脑 |
| --- | --- |
| 给油前进 | W 或 ↑ |
| 减速后倒车 | S 或 ↓ |
| 转向 | A / D 或 ← / → |
| 刹车 / 起漂 | B，配合转向 |
| 喷气加速 | Shift |
| 跳跃 / 持续腾空 | 空格 |
| 吸地开关 | E |
| 左右侧喷 | Q / F |
| 左右单圈翻滚 | 点按 Z / X |
| 切换追尾视角 | C |
| 暂停 | Esc / P |

手机左侧轮盘使用圆形范围和各轴独立死区，斜向上推仍可达到全油门，避免转弯时油门意外减小。小幅转向采用柔和曲线，高速限制转向速度，松手或反打更快响应；普通行驶轮胎抓地更强，不会自动对准赛道。空中转向会启动侧喷。右侧四颗等大圆键固定为上排吸地、跳跃，下排刹车、加速。吸地点按开关，其他三键按住生效；吸地、翻滚和暂停均可在另一根手指持续操纵轮盘时触发，每次触碰只触发一次；加速上滑到跳跃可同时推进和腾空，支持多指操作。

腾空后自动在四键上方显示左右两颗等大翻滚键，落地收起，常用按钮不会移动。点按完成单圈并回正，每次扣 10% 气压；高度不足、吸地开启或气压不够会在按钮内提示，不接受重复排队。翻滚完成后仍需安全落地才记分。桌面 Z / X 也采用单次触发。

车速与计分置顶，血量、气压、路况和得分反馈集中在左上，中央留给赛道。操作区与底边留出握持间距，窄屏和矮屏横屏使用紧凑布局。

手机只提供横屏玩法。开始时尝试系统全屏及方向锁定；不支持的浏览器由外层自动旋转画面。直接进入 `/game/index.html` 也会回到横屏入口。

## 地图与计分

- **霓虹都市**：城市高架、路障、断口和墙面驾驶。
- **赤岩峡谷**：起伏路面、连续弯道和断桥。
- **近地轨道**：低重力、长跨度跳跃和悬浮翻转赛道。

镜头随车速增加前方预览距离，并平滑瞄准点；路边增加弯道箭头、外侧反光路肩，提前辨认弯向。漂移蓝／金／紫三档同时反馈在火花、左上进度和刹车按钮外环；松刹提示在按钮内。

三张地图均无终点，以 640 米路段流式生成，最多保留四段，及时释放身后的几何体、材质和纹理。场景使用实例化，喷气和漂移共用固定粒子池，物理固定 120 Hz。设置支持流畅、均衡、高清；实际帧率依设备而定。

总分 = 最远推进距离 × 2 + 穿环 × 150 + 成功漂移距离 × 4 + 安全翻滚 × 600 + 平稳落地 × 200 + 高速擦身 × 250 + 反重力路段 × 500 + 连续动作奖励。

翻滚仅在安全落地后结算。5 秒内连续完成穿环、漂移、着陆、擦身或反重力路段，CHAIN 最高叠至 5，每个新动作额外奖励 0 / 100 / 200 / 300 / 400 分。碰撞打断连续奖励，保留已经获得的分数。

倒车不会扣除最远推进距离，但再次经过旧路段不会重复获得距离分。光环、擦身和反重力路段按唯一标识结算，重新加载旧路段也不会刷新奖励。漂移只给向新路段推进的距离奖励。

每位玩家每张地图保留最高成绩，在线显示前 20 名。手动模式使用独立的 `manual-v3` 榜单；旧版自动驾驶 `endless-v2` 和定长赛道成绩仍保留在旧存储中，不与新驾驶规则混排。

## 排行榜与 Vercel

Next.js Node Functions + 私有 Vercel Blob。连接 Blob 后使用服务器环境变量 `BLOB_READ_WRITE_TOKEN`；不允许将密钥设置为 `NEXT_PUBLIC_`。本地默认写入 Git 忽略的 `.local/manual-v3/`，浏览器也保存本机成绩。离线可玩，本轮无法伪装上传。

开始时签发版本化 HMAC 凭证，有效期 7 天。提交时验证玩家、时长、距离和特技范围，并用客户端与服务器共用的规则重新计分。使用 nonce 防重放及 Blob ETag 条件写入，防止并发覆盖。此为休闲排行榜，客户端物理不是服务器逐帧权威模拟。

```sh
npm test           # 三地图各 9.6 km、手动驾驶/倒车、无弯道跟随、漂移档位、血量、坠落挽救、回吸、翻滚、分块释放、多指输入、单次翻滚与可用性
npm run typecheck
npm run build
npm run test:api   # 先启动本地服务器，测试新榜单、参数拒绝与重复提交保护
```

主要代码：`public/game/physics.js` 驾驶规则，`rules.js` 气压与共同计分，`world.js` 流式地图及翻转几何，`game.js` 流程/镜头/HUD，`touch.css` 手机与桌面布局，`app/api/` 和 `lib/leaderboard.ts` 在线成绩。

## 模型与设计参考

车辆依据白色 Roadster 公开正侧后照片重建，包含楔形车身、金色座舱、五辐轮毂、可动尾翼和多方向喷口。**这是照片参考的游戏模型，不是官方 CAD，未达到每个曲面和尺寸完全相同。** [车型照片参考](https://www.caranddriver.com/photos/a74152579/tesla-roadster-revealed-exterior-gallery/)。

漂移蓄力、出弯奖励参考 [Nintendo 马里奥赛车操作指南](https://www.nintendo.com/jp/ichikara/aabpa/index_en.html)；漂移、擦身的技巧奖励参考 [EA 极品飞车游戏手册](https://eaassets-a.akamaihd.net/eahelp/manuals/need-for-speed-the-run-manuals_PC.pdf)。气压循环、手动驾驶、无尽规则与数值为本项目自己的设计，没有使用这些游戏的素材。

触控布局参考 [Apple 游戏控制设计指南](https://developer.apple.com/design/human-interface-guidelines/game-controls)：分配左右手操作区，按游戏状态显示可用动作，避免遮住场景中心。
