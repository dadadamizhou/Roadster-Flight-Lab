# Roadster Flight Lab

一个可在浏览器运行的 3D 喷气跑车游戏。桌面键盘和手机触控均可操作，默认开启自动油门。

## 启动

Mac 双击 `启动游戏.command`，然后打开终端显示的地址。

```sh
npm ci
npm run dev
```

游戏地址：<http://127.0.0.1:5173/>。需要 Node.js 22 或更新版本。资源和 Three.js 已保存在本地，不依赖运行时 CDN。

## 驾驶与资源

| 操作 | 按键 | 资源 / 效果 |
| --- | --- | --- |
| 普通加速 / 刹车 | W / S 或 ↑ / ↓ | 行驶耗电，刹车少量回收 |
| 左右转向 | A / D 或 ← / → | 地面转向；空中启用侧喷耗气 |
| 后喷推进 | Shift（按住） | 加速，消耗气压 |
| 下喷腾空 | 空格（按住） | 垂直推力，消耗气压 |
| 左右侧喷 | Q / F（按住） | 地面或空中横移，消耗气压 |
| 左右翻滚 | Z / X（按住） | 空中整周翻滚，消耗气压，松手辅助回正 |
| 吸地风扇 | E（切换） | 耗电，减少弯道侧滑；空中辅助下压 |
| 压缩机充气 | R（切换） | 随时开启，行驶中耗电补气；满罐自动停止 |
| 切换视角 | C | 标准 / 近距追尾 |
| 暂停 | Esc / P | 暂停比赛和资源消耗 |

手机采用双拇指圆形按键：左侧使用模拟摇杆，左右拖动转向，松手回中；右侧上方跳跃、下方加速，内侧刹车，三颗圆键同样大小。按住加速向上滑到跳跃键可同时推进与腾空，向下滑恢复单独加速，松手结束；也支持多指同时按住。手机加速键同时给普通油门，气压耗尽时仍可用电行驶。「特技」展开侧喷与翻滚，补气、吸地仍为点按开关。手机固定使用横屏布局，速度表在上方，操作键与底部留有握持间距。点击开始时尝试全屏并锁定系统横屏；浏览器不支持锁定时，外层自动旋转游戏画面，仍不提供竖屏玩法。直接访问 `/game/index.html` 也会回到横屏入口。

绿色补给区内减速到 25 km/h 以下即可给电池充电。气压和电量是两套独立资源。普通驾驶最高速度与喷气加速不同。侧翻着陆、路障碰撞和掉出赛道会扣分；掉出赛道回到最近安全点。

## 地图和计分

- 霓虹都市：1.8 km，弯道、路障、高架断口。
- 赤岩峡谷：2.0 km，起伏路面、连续断桥。
- 近地轨道：2.2 km，低重力、长跨度悬浮赛道。

每张地图有 12 个能量环。基础分 15,000，每秒扣 35 分，穿环加 800，平稳着陆加 250（最多 12 次），碰撞扣 650。每位玩家各地图保留最佳成绩，在线显示前 20 名。

## 在线排行榜与 Vercel

Vercel 部署使用 Next.js Node Functions 和私有 Vercel Blob。将私有 Blob 存储连接到项目后，Vercel 自动提供 `BLOB_READ_WRITE_TOKEN`。密钥只在服务器使用，不能加 `NEXT_PUBLIC_` 前缀。

本地开发默认写入被 Git 忽略的 `.local/`，不触碰线上排行榜；浏览器同时保留本机成绩。没有网络时仍能玩，本轮成绩不会伪装成已成功上传。

比赛开始时签发 HMAC 比赛凭证，提交时验证时长、参数和重放，服务器重新计算分数。Blob 条件写入避免并发覆盖。当前属于休闲排行榜，浏览器物理不是服务器逐帧权威模拟，不适用于现金赛事。

```sh
npm test             # 物理、能源、三张地图、侧喷与翻滚
node tests/touch-input.test.mjs # 多指触控、上滑组合、松手和失焦清理
npm run typecheck
npm run build
npm run test:api     # 先启动本地服务器，约需 23 秒
```

## 代码位置

- `public/game/model.js`：程序化车辆几何、轮毂、尾翼、喷口。
- `public/game/physics.js`：驾驶、气压、电池、抓地、飞行与地图参数。
- `public/game/world.js`：城市、峡谷、太空赛道与实例化场景。
- `public/game/game.js`：镜头、输入、粒子、音效、HUD 与流程。
- `public/game/style.css`：桌面和触控界面。
- `app/api/`、`lib/leaderboard.ts`：比赛凭证、校验与持久化排行榜。

## 模型与性能

车辆依据 2026 年发布会白色 Roadster 的公开正侧后照片建模，包含楔形车身、金色座舱、五辐轮毂、可动尾翼和多方向喷口。**这是照片参考重建的游戏模型，不是官方 CAD，未达到每个曲面和尺寸完全相同。** 参考：[发布会车型图片](https://www.caranddriver.com/photos/a74152579/tesla-roadster-revealed-exterior-gallery/)。

使用 Three.js、批量实例化场景、固定 120 Hz 物理步进、固定粒子池与有限像素密度；设置支持流畅、均衡、高清。帧率取决于设备与屏幕分辨率。场景为程序生成，网络无需下载大型模型或贴图。

Three.js 0.169.0 的 MIT 许可证位于 `public/game/vendor/THREE-LICENSE.txt`。
